## 单块导出（关键提速技巧）

AnimeStudio 全量扫 9450 个块很慢且会撞 shader 崩溃。
**先从 map 定位 block，再只处理那一个**：

```bash
grep -a -B 30 "characters/npc/special/xxx/model/xxx_model.fbx" maps/full/full_map.json \
  | grep -aoE "[0-9a-f]{32}\.block"
# 复制该 block 到临时目录，只对它跑 AnimeStudio
```

`npc/special/paraprince_00` 整组（6 个文件）用这招**几秒**完成，
全量方式则 7 分钟零产出。

## 渲染管线关键坑（已解）

1. 正面 = -Y（眼睛法线≈(-0.01,-1.00,-0.08)）
2. **最终方案（render_rebuild.py）**：① 材质全部"推倒重建"（清空节点树→新Principled+贴图直连+OPAQUE）——因为每个 Art 文件的原始材质节点链/混合模式（BLEND/HASHED混杂）各不相同，在上面打补丁不可控（表现为某些皮肤眼睛层被吞掉，且逐文件随机）；② 眼睛网格沿局部 -y 前移 0.03（消除与脸面的 z-fighting；眼睛板与脸面几何上仅差 1e-5，完全共面）；③ 相机 clip 收紧到 2.0 提高深度精度。
3. 眼睛贴图是表情图集 → 需重铺选择一个"正常睁眼"sprite 进 u[0.0044,0.5]/[0.5,0.9964]×v[0.2545,0.776] 两区（`eyefix_all.py` 自动检测每皮肤首块大部件=正常睁眼，已逐一验证颜色：浪浪仙紫/晴天蓝/嘤嘤子淡紫/咪奈花粉/棒球狸金）
4. 脚本一律 write_file 落地再跑（heredoc 引号坑）
5. 验证方法：与"删眼基线"逐像素 diff，眼睛层贡献必须集中在脸部区域（~15k-23k 像素；若为 0 = 被吞）
