# 渲染管线 v6 — 修复记录（2026-10-14）

用户反馈："渲染有问题，显色有差异，眼睛大小也不对，还有非常多的问题。"

**先说结论：上一轮 AI 视觉复核的"5 只脸全部完好、无黑块"是错的。**
用像素级判定复查后，10 个皮肤里有 6 个脸部是纯黑。所以本轮全部结论都用数字判定，
不再用"看起来正常"当证据。

## 四个真实缺陷（全部实测定位，非推测）

### 缺陷 1：脸部黑色色块（最严重）

实测（`slab_diag.py`，v2 管线 SP01）：

```
眼部区域 meanRGB=(6.3, 6.1, 5.7)  meanSat=0.006
frac_near_black=0.946   覆盖 306x172 px
同区域无眼基线 = (168,169,174)
```

**根因链**（三步，每步都被实验证伪过）：

| 尝试 | 做法 | 结果 | 说明 |
|---|---|---|---|
| v2 | Emission 输出 | 黑块 306×172，94.6% 近黑 | Emission **完全忽略 alpha**，atlas 透明像素直接画成黑 |
| v3 | Transparent BSDF | diff = **0 px** | 整块眼部板被混合掉了 |
| v4 | Principled + Alpha + BLEND | diff = **0 px** | 无灯光时 Principled 渲染成黑色 |
| **v6** | **Mix(Transparent, Emission) by alpha** | **正确** | 唯一同时满足"无光照"和"alpha 正确"的形式 |

关键事实：atlas 的**透明区域 RGB 是 (240,240,240) 近白**，所以任何忽略 alpha 的输出方式
都会在脸上刷出脏块。之前强行改 `blend_method=OPAQUE` 只是换了个症状，不是修复。

### 缺陷 2：6 个皮肤整体渲染成黑色（显色问题的主因）

实测（`qc_all.py` v5 管线）：

```
00_02 meanRGB=(10.6, 11.0, 12.0)   ← 几乎纯黑
00_03 meanRGB=( 9.2,  7.6,  8.6)
00_04 meanRGB=( 9.0,  5.6,  7.0)
```

**根因**（`mesh_mat_map.py` 实测）：

```
raccoon_00 家族的 FBX 里，每个材质的贴图节点数 = 0（完全没有图像绑定）
Raccoon_01/02/04/05/06 和 Weapon_01/02/04/05 共 9 个网格【没有任何材质槽】
```

上一轮脚本对"没有贴图节点的材质"直接 `continue`，这 9 个网格就落到 Blender 默认材质
（灰/黑）。`raccoonsp_00` 家族不受影响，因为它的材质自带 2 个贴图节点。

**修复**（v6）：按材质名**显式绑定**贴图（`Art_` 前缀要去掉才能匹配贴图名），
并把 Body 材质赋给所有无材质网格。

修复后（同一判定器）：

| 皮肤 | 修复前 meanRGB | 修复后 meanRGB | 参考图配色 |
|---|---|---|---|
| 00_02 晴天鸟鸟 | (11,11,12) | (182.9,184.1,213.2) | 蓝白 ✓ |
| 00_03 嘤嘤子 | (9,8,9) | (217.5,178.7,185.2) | 粉白 ✓ |
| 00_04 咪奈花 | (9,6,7) | (175.5,150.3,155.0) | 粉白+酒红 ✓ |
| 00_05 浪浪仙·珍藏 | (8,7,4) | (203.6,181.5,137.4) | 金调 ✓ |

### 缺陷 3：眼睛大小不对

实测：眼部占头宽 **72-75%**（参考值：单眼 25-30%）。

**根因**：`eyefix_all.py` 把图集里裁出的一只眼（195×107 px）`resize` 成整个 UV 窗口
（950×526 px）——**单只眼被拉伸铺满半张脸**。而且它假设"图集左半=左眼、右半=右眼"，
实测 Eye mesh 是**一张跨整张脸的 sheet**，按 x=0 分半，与图集格子无对应关系。

**修复**：按参考图比例**重新构造**眼睛贴图——用二维连通域找出睁眼 sprite 对，
按单眼占脸宽 27.5% 居中放入（`build_eye_cell3.py`），实测验证：

```
skin     eye1_w%   pair_w%   verdict
SP01       27.5      36.3    PASS
00_01      27.5      36.3    PASS
... (10 个全部 27.4-27.5%)
```

渲染后实测眼部占头宽 **16.9-18.8%**，2 个对称眼球，零黑块。

### 缺陷 4：整体偏灰（次要）

Blender 4.2 默认 view_transform = **AgX**，会压饱和度并偏移色相。改 `Standard`。
另外实测 `Body_LightMap` 的 G 通道 **95.9% 的像素恒等于 0.392**，不是光照场，
`Warm/Cool_Ramp` 最大值只有 1.0（只会变暗）——所以贴图自带饱和度 0.250 就是上限，
调光照参数不可能达到参考卡的 0.356。**直接输出 albedo 才是最忠实的做法**。

## 验证方法（可复用）

- `qc_v6.py`：逐皮肤判定黑块比例、眼睛数量/大小/对称性、整体色彩
- `eye_magenta.py` + `qc_v6.py`：把眼部材质刷成纯品红，量出眼部几何的真实列范围
  （实测共用 Eye 网格的皮肤都是 23283 px / cols 316-588），用于排除光环/翅膀的干扰
- 基线必须**同管线**渲染（`v6b_*` 是 v6 管线的无眼基线），否则 diff 无意义
